# controle-estoque
# Sistema de Controle de Estoque
Projeto da disciplina Práticas de Programação

# Sobre o projeto
Sistema simples de controle de estoque para uma pequena loja, desenvolvido em Python e executado no terminal (modo console). O estoque é representado por uma lista de dicionários, e cada dicionário é um produto com código, nome, preço e quantidade. Os dados ficam disponíveis apenas durante a execução do programa.

# Funcionalidades
1. Cadastrar produto: solicita código, nome, preço e quantidade. Não permite código duplicado nem preço ou quantidade negativos.
2. Calcular total de produtos em estoque: soma as quantidades de todos os produtos cadastrados e exibe o resultado.
3. Sair: encerra o programa.

# Conceitos utilizados
- Funções
- Listas
- Dicionários
- Estruturas de repetição e condição

# Como executar
É necessário ter o Python 3 instalado. No terminal, dentro da pasta do projeto:

    python pti.py
